# Базар

Якщо тулів `bazar__*` немає, попроси користувача підключити `mono-ecommerce` на вкладці Connectors плагіна і
підтвердити вхід у застосунку monobank.

- **Огляд:** `bazar__list_my_advertisements`. Спершу те, що потребує дії продавця, решту — коротко.
- **Зміни:** знайди через `bazar__find_my_advertisement` (кілька збігів — перепитай), покажи поточне й нове
  значення, отримай «так», тоді змінюй.
- **Фото:** `bazar__create_photo_upload_link`, виконай його команду для файлу, який користувач прикріпив, далі
  використай `photoUploadId`. Фото лише в телефоні — тоді тільки через застосунок mono.
- **Нове оголошення:** фото → `bazar__create_advertisement_draft` зі слів самого користувача → питання Базару →
  покажи результат → публікуй лише після «так».
- **Видалення:** назавжди. Покажи саме це оголошення й отримай «так» саме на нього.

Нічого не вигадуй про товар. Повторюючи ту саму дію, передавай той самий `idempotencyKey`.
