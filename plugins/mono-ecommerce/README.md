# mono e-commerce

Маркет і Базар від monobank — прямо в Claude.

- **Маркет** — знайти й порівняти товари, зібрати кошик, оплатити в застосунку monobank, стежити за замовленнями.
- **Базар** — для продавців: що відбувається з оголошеннями, зміна ціни, назви чи опису, фото, нові оголошення.

Встановіть плагін, натисніть **Connect** біля `mono-ecommerce` і підтвердіть вхід у застосунку monobank.

## Дані поза конектором

Усе, крім фото, йде через конектор `mono-ecommerce`. Фото для Базару — єдиний виняток:

- **Що:** лише файл фото, який ви прикріпили до розмови й попросили додати до оголошення.
- **Куди:** `https://ai.monoecom.tech/photos/…` — сервер того самого конектора, за одноразовим посиланням, що живе
  10 хвилин.
- **Як:** Claude надсилає файл зі свого середовища виконання коду, а не через конектор, тому домен треба дозволити:
  Settings → Capabilities → мережевий доступ для виконання коду → додати `ai.monoecom.tech` (на Team/Enterprise —
  власник організації).

Без цього дозволу не працюють лише фото й нові оголошення на Базарі.
